# 360° Best Employee Survey - LIFE Ecosystem

Dashboard untuk mengelola survei 360° karyawan di LIFE Ecosystem dengan sistem NPS (Net Promoter Score).

## 🌟 Fitur Utama

- **Dashboard Overview** - Monitoring real-time survey completion
- **Employee Management** - CRUD karyawan dengan filtering & search
- **Parameters Management** - Kelola pilar dan pertanyaan survey
- **Survey Period Management** - Generate & distribute unique survey links
- **Reports & NPS Rankings** - Analisis dan ranking berdasarkan NPS Score

## 🎨 Tech Stack

- React 18
- Tailwind CSS
- Lucide React Icons
- Laravel (Backend - Coming Soon)
- Google Sheets (Data Storage)

## 🚀 Installation
```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/lpp-survey-360.git

# Install dependencies
cd lpp-survey-360
npm install

# Run development server
npm start
```

## 🔧 Environment
Tambahkan file `.env.local` di root project dengan isi:

```env
NEXT_PUBLIC_API_BASE_URL=https://your-domain.test/api
```

Next.js akan membaca file ini otomatis saat development maupun build.

## 📦 Build for Production
```bash
npm run build
```
